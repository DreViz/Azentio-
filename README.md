# Azentio.ai Build Labs: Special Challenge

The azentio.ai website and a secure collaboration portal with governed collective learning.

**Every privacy promise on this portal has a test you can run.** Access is enforced by Postgres row-level security, the private source and the shared copy are separate records, and withdrawal reaches search and the AIRA assistant at once. A live Trust Proof page attacks the system as each persona.
